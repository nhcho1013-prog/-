# 오사카 · 교토 여행 (2026.12.13 – 12.17)

아이폰에서 앱처럼 쓰는 5일 여행 일정 웹앱. 빌드 없이 `index.html` 하나로 동작해요.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 본체 (HTML + CSS + JS 전부 포함, 외부 의존 없음) |
| `icon-180.png`, `icon-512.png` | 홈 화면 아이콘 |
| `manifest.webmanifest` | PWA 설정 (전체 화면 실행) |

## 여는 방법

- **아이폰 (지금 쓰는 방법)**: Safari로 이 저장소의 Pages 주소를 연 뒤 **공유 → 홈 화면에 추가**. 주소창 없이 앱처럼 실행됩니다.
- **무료 호스팅**: 이 폴더를 그대로 GitHub Pages, Vercel, Netlify에 올리면 끝 (빌드 설정 없음).
  - GitHub: 저장소에 폴더를 올리고 Settings → Pages → Branch를 `main` / root로 지정.
- **PC에서 미리보기**: `python3 -m http.server` 로 폴더를 열고 브라우저에서 확인.

## 기능

- **일정** — 1~5일차 탭(12.13 일 ~ 12.17 목). 카드를 탭해 완료 표시, 카드 본문을 탭해 시간·장소·메모 수정, `＋`로 일정 추가.
- **장소** — 숙소 / 식당 / 명소 22곳. 카드를 누르면 구글 지도에서 바로 검색.
- **체크** — 출발 전 준비물 + 짐 싸기 체크리스트. 항목 추가·삭제 가능.
- **메모·경비** — 자유 메모(자동 저장), 엔화/원화 경비 기록과 합계.
- **설정(오른쪽 위)** — 기본 일정으로 되돌리기, 체크리스트 초기화, 경비 비우기, 전체 초기화.
- 모든 변경은 `localStorage`(`oktrip.v1`)에 저장돼 앱을 닫아도 남습니다.
- 헤더의 D-day는 2026.12.13을 기준으로 오늘 날짜에서 자동 계산됩니다.
