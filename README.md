## 화면 · 기능

- **일정** — 1~5일차 탭(12.13 일 ~ 12.17 목). 날짜 헤더 아래에 **일차별 동선 지도**.
  - OpenStreetMap + Leaflet, 번호 핀(1→2→3…)과 연결선. 그날 일정 중 좌표가 있는 곳만 표시.
  - 오사카↔교토처럼 멀리 떨어진 날은 `전체 동선 / 오사카 / 교토` 칩으로 나눠서 봄 (기본은 장소가 많은 동네).
  - 같은 자리에 겹치는 일정(숙소 체크인·복귀 등)은 하나의 핀으로 묶여 시간이 함께 표시됨.
  - 접기/펼치기 가능. 핀을 누르면 번호·장소명(일본어)·분류·시간·일차·메모가 담긴 **하단 정보 카드**가 뜸.
    - 핀은 선택 표시(확대·강조)되고 카드에 가리지 않게 지도가 부드럽게 이동.
    - 카드의 `‹ ›` 로 그날 핀을 순서대로 넘겨보기, `구글맵 열기`로 바로 길찾기, `일정 보기`로 타임라인의 해당 카드로 이동, `✕`나 지도 배경 탭으로 닫기.
    - 두 번째 핀부터는 **`이전 장소 → 여기`** 버튼이 생겨 구글 지도 대중교통 길찾기가 바로 열림 (첫 핀은 숨김).
  - 카드를 탭해 완료 표시, 카드 본문을 탭해 시간·장소·좌표·메모 수정, `＋`로 일정 추가.
- **영업시간 배지** — 주요 식당·명소 카드에 영업시간과 정기휴무를 배지로 표시.
  - 계획한 날짜·시간과 비교해 `영업 중 · 곧 마감 · 개점 전 · 브레이크 타임 · 영업 종료 · 정기휴무` 를 색으로 구분.
  - 시장·상점가처럼 매장별로 다른 곳은 `매장별 상이` 로 표시. 확인하지 못한 곳은 배지를 달지 않음.
- **장소** — 숙소 / 식당 / 명소 23곳. 카드를 누르면 구글 지도에서 바로 검색.
- **추천** — 일정 사이 빈 시간에 맞춘 주변 코스 20개(1일차 4 · 2일차 4 · 3일차 4 · 4일차 4 · 5일차 4).
  - 일차별 필터(전체 / 1~5일차), 각 카드에 시간대·도보 거리·추천 이유·구글 지도 링크.
  - **`+ N일차 일정에 추가`** 를 누르면 시간 순서에 맞는 자리에 들어가고, 그날 동선 지도에도 핀으로 표시됨.
- **체크** — 출발 전 준비물 + 짐 싸기 체크리스트. 항목 추가·삭제 가능.
- **메모** — 엔화/원화 경비 기록과 합계, 자유 메모(자동 저장).
  - 맨 위에 **JPY ↔ KRW 환율 계산기**: 엔화를 넣으면 원화가, 원화를 넣으면 엔화가 바로 계산됨.
    - `100엔 = ○○원` 환율은 직접 고칠 수 있고, 바꾼 값은 저장됨 (`기준 환율` 로 되돌리기).
    - `¥500 · ¥1,000 · ¥2,000 · ¥5,000 · ¥10,000` 빠른 버튼.
- **설정(오른쪽 위)** — **백업 · 복원**(JSON 내보내기: 복사·파일로 저장 / 붙여넣어 불러오기), 기본 일정으로 되돌리기, 체크리스트 초기화, 경비 비우기, 전체 초기화.
- 모든 변경은 `localStorage`(`oktrip.v1`)에 저장돼 앱을 닫아도 남습니다.
- 헤더의 D-day는 2026.12.13을 기준으로 오늘 날짜에서 자동 계산됩니다.
